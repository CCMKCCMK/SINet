# Satellite IoT Measurement Dataset (IMC'25)

This repository provides the dataset associated with our paper on satellite IoT measurements.  
It contains real-world measurement results and supporting data used in our measurements of Direct-to-Satellite (DtS) IoT systems.
Contents

## Contents

- **TLE Data**  
  Two-Line Element (TLE) data used to predict satellite passes and calculate theoretical visibility durations.  

- **Beacon Reception Data**  
  Received Beacons from globally deployed ground stations that capture satellite Beacons, enabling analysis of satellite availability and geographic diversity.  

- **Tianqi Terminal Communication Logs**  
  Logs from standard commercial Tianqi IoT terminals, recording uplink and downlink transmissions under practical operating conditions of Tianqi constellation.  

A detailed description of data formats and usage instructions will be released soon.
